
# Sales & Revenue Analysis Dashboard

## Project Overview
An interactive Sales & Revenue Analysis Dashboard developed using Microsoft Power BI to analyze sales performance and generate meaningful business insights.

## Key Features
- Total Sales, Profit, and Units Sold KPIs
- Country-wise Sales Analysis
- Product-wise Sales Performance
- Monthly Sales Trend Analysis
- Segment-wise Sales Distribution
- Interactive Country and Date Filters

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis
